# 流程
process_title: "我们如何交付"
process_subtitle: "工程师驱动的服务，每一步都可衡量、可审计、可复盘。"
process:
  - step: "Step 01"
    title: "对齐 (Discovery)"
    description: "用 1-2 次会议梳理客户场景、目标与约束，形成明确的范围与可交付物。"
  - step: "Step 02"
    title: "方案 (Design)"
    description: "输出方案文档与时间表，确认资源投入、里程碑与验收标准。"
  - step: "Step 03"
    title: "交付 (Delivery)"
    description: "按里程碑执行，工程师周报 + 数据透明，客户对项目状态全程可见。"
  - step: "Step 04"
    title: "复盘 (Review)"
    description: "项目结束完整知识转移，文档、Runbook、源代码全部交给客户，绝不锁定。"
  - step: "Step 05"
    title: "持续 (Continuity)"
    description: "如有持续需求，转入长期合作模式；否则保持联系，按需复访。"
